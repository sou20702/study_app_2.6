# 勉強大好きアプリ（海中の生態系版）

学習（タイマー・課題）の積み重ねが、海の生き物として世界に反映されるアプリです。
「修練」機能と島開拓機能は削除しました。

## 起動手順（XAMPP）

1. XAMPP Control Panel で Apache と MySQL を起動する
2. このフォルダごと `htdocs` に置く
3. `http://localhost/phpmyadmin/` の SQL タブに `db/study_app.sql` の内容を貼って実行する（DB「study_app」を作成）
4. `http://localhost/フォルダ名/index.php` を開く（表は初回アクセス時に自動で作られます。旧バージョンのDBもそのまま使えます）

動作環境：PHP 8.x / MySQL 8.0 以上 または MariaDB / Chrome・Safari 最新版

| タブ | ファイル | 内容 |

## ポイント・進化レベル・世界のルール

| 獲得元 | ポイントの決まり方 | 進化レベルが1上がる条件 |
|---|---|---|
| タイマー | 勉強＋休憩で30分（25+5）ごとに1ポイント。端数は次回へ繰り越し。90分なら3ポイント | 3ポイントで1上がる |
| 課題 | 算出スコア（p）に応じて変動。100p＝1ポイントとして歴史に記録 | 100pで1上がる（2〜3課題が目安） |

- ポイントを獲得すると「ポイントを獲得しました」のポップアップが出て、そこからキャプションを追加できます。
- 数値は **`config/game_config.php`** だけで調整できます。

### 世界の広がり方

- **進化レベルが1上がるごとに、生き物が1匹増えます。** 1つの海域に現れる生き物は10匹で、5海域の合計は50匹（進化レベルの上限は50）です。
- **背景は海域ごとに5段階（Lv1〜Lv5）。** 最初はLv1で、その海域の生き物が2匹増えるごとに次のレベルへ進みます（0匹→Lv1、2匹→Lv2、4匹→Lv3、6匹→Lv4、8匹→Lv5）。Lv5になったあとも、10匹になるまで生き物は増えます。
- **海域は進化レベルに応じて解放されます。** 最初は中央海域だけで、進化レベルが5を超えると浅瀬、10を超えるとサンゴ礁、15を超えると熱水噴出孔、20を超えると深海エリアが解放されます。解放された海域は、そのレベルアップですぐ1匹目が誕生します。
- 解放されたあとは、いちばん長く増えていない海域から順に生き物が増えるので、変化が1つの海域に偏りません（`config/growth_lib.php` の `world_schedule()`）。
- 生き物が誕生すると「新たな生物が誕生しました。」、背景が進化すると「時がたち、海域が変化しました。」とポップアップに表示されます（海域が解放されたときは「新しい海域が解放されました。」も出ます）。

## ホームの描画を差し替えるには（描画担当向け）

海の描画は、**背景**と**生き物**を別々の画像で差し替えられます。どちらも、置いていないものは仮のデモ表示のままで、途中までしか揃っていなくても動きます。泡（ぽこぽこ上がっていく粒）は、背景の画像の上にもそのまま表示されます。

### 背景（100×50px・25枚）

`img/backgrounds/{海域キー}_{レベル}.png`（例：`center_1.png`）

- 海域キー：`center`（中央海域）/ `shallow`（浅瀬）/ `coral`（サンゴ礁）/ `vent`（熱水噴出孔）/ `deep`（深海エリア）
- レベル：1〜5（Lv1が最初の背景。生き物が2匹増えるごとに次のレベルへ）
- 100×50px のドット絵は、そのまま整数倍で拡大されます（大きい画像は滑らかに縮小されます）。

### 生き物（50枚）

`img/creatures/{海域キー}_{番号}.png`（例：`coral_3.png`）

- 海域は5つ、番号は各海域1〜10です。番号の小さい順に誕生します（その海域の1匹目が1番）。
- どの番号がどんな生き物の枠か、海底に置くか泳ぐかは、`生き物リスト_50枚.xlsx` の一覧にあります（元データは `js/world.js` の `THEME` の `items`）。
- 一覧は仮の目安です。枠が「さかな」でも、別の生き物の絵を置いて構いません（ただし海底に置く枠か、泳ぐ枠かは番号で決まっています）。
- 種類ごとの絵（使い回し）も使えます：`img/creatures/{名前}.png`（`fish` `coral` `jelly` `crab` `turtle` `whale` `angler` `seaweed` `starfish` `tube`）。1匹ごとの絵がない枠だけ、この絵が使われます。

### 画像の扱い（生き物）

- **背景が透明のPNG**：そのまま重なります。
- **スキャンしたままの白い背景**：白い部分が自動で消えて、海になじみます（ただし白に近い色は消えるので、白い生き物は透明PNGで）。
- 向きはランダムに左右反転して表示されます。
- 表示サイズは `js/world.js` の `CREATURE_W`（種類ごと）と `SLOT_W`（1匹ごと）で調整できます。
- 絵の描き方のコツ：紙に黒や濃い色で輪郭を描き、スキャンは余白を少なめにトリミングして、幅300〜600px程度の画像にする。
- 描画そのものを作り直す場合は、`js/world.js` の `draw()` を差し替えます。世界の状態は `window.WORLD_STATE`（`api/world_state.php` と同じJSON）で渡されます。

海域を増やすときは `config/game_config.php` の `get_world_areas()` に位置（x, y）と解放条件（`unlock_after`）つきで追加します。

## UI・操作性

- 青基調・四角いデザイン・ドット調フォント（DotGothic16。オフライン時は `fonts/README.txt` を参照）
- エラー・お知らせは画面内のトースト表示。DB接続エラーなどもアプリ内のエラー画面（再読み込みボタン付き）
- 削除・退出などの確認は、ブラウザ標準の確認ではなく、画面内の確認ダイアログで行います（フォームに `data-confirm` を付けると使えます）
- 戻るボタンが必要になる画面遷移をなくしました（ボトルメールの送受信・課題の完了と編集はその場で完結）
- 課題一覧の並び替えは、表の見出しのボタンをやめて、一覧の上の「並び順」から選ぶ形にしました

## BGM・効果音（音の「枠」）

`audio/` フォルダに、次のファイル名で mp3 を置くだけで鳴ります。置かれていない音は、何も鳴らさずに進みます（エラーにはなりません）。

| ファイル名 | 鳴るタイミング |
|---|---|
| `bgm_1.mp3` / `bgm_2.mp3` / `bgm_3.mp3` | ゲーム内BGM（3種類。設定タブで選ぶ）。勉強中（タイマー）のBGMも兼ねる。アプリを開いている間、くり返し再生 |
| `se_timer.mp3` | タイマー（予定の時間になったとき）。無いときは従来のピピピ音 |
| `se_task_done.mp3` | 課題完了 |
| `se_point.mp3` | ポイント獲得 |
| `se_stage_up.mp3` | 進化（新たな生物が誕生したとき。ポイント獲得音のあとに続けて鳴る） |
| `se_mail_send.mp3` | メール送信（ボトルを流したとき） |
| `se_mail_open.mp3` | メール開封（ボトルを拾ったとき） |

- 効果音は重ならないよう、順番に1つずつ鳴ります（例：課題完了 → ポイント獲得 → 進化）。
- ブラウザの決まりで、BGMは画面を1回操作（クリックなど）してから鳴り始めます。画面を移動しても、続きから流れます。
- BGMの初期設定は「BGMなし」です。聴きたいときは設定タブで選びます（選んだ内容はこのブラウザに保存されます）。
- BGMの名前は初期状態では「BGM 1」「BGM 2」「BGM 3」です。`config/credits.php` の `title` に書くと、設定タブのBGM選択に反映されます。
- ファイル名や拡張子を変えるときは `js/sound.js` の `SE_FILES` / `BGM_TRACKS` を書き換えます。

## 設定タブ

| 項目 | 内容 |
|---|---|
| 言語 | 日本語 / English を切り替え（画面が自動で読み込み直されます）。このブラウザに保存 |
| サウンド | BGMの選択（3種類。音源がまだ無いものは選べない）、ミュート、BGMの音量、効果音の音量、効果音の試し再生 |
| リセット | 「設定を初期値に戻す」（言語・サウンド）と「ゲームの進行をリセット」（ポイント・進化レベル・歴史を消す。課題・グループ・手紙は残る。タイマーの学習記録も消すかは選べる） |
| 問い合わせ | 種類（不具合の報告・要望・その他）と内容を送信。`inquiries` テーブルに保存され、phpMyAdmin で確認できる |

- 問い合わせ先のメールアドレスを `config/game_config.php` の `CONTACT_EMAIL` に書くと、設定タブに「メールで送る」ボタンも表示されます。
- 英語の文言は `js/i18n.js` の `EN`（「日本語: 英語」の一覧）にあります。新しい文言を足したときは、ここに英訳を追加してください。ユーザーが入力した文字には `data-no-i18n` を付けると訳されません。

## クレジット（音源・素材の出どころ）

設定タブの下に「クレジット」欄があります。表示される内容は **`config/credits.php`** に書きます（BGM 3種、効果音6種、画像、フォント・ライブラリ）。

- 空欄の項目は「（未入力）」と表示されます。曲名・作者・サイト名・URL・利用条件を、あとから書き足してください。
- URL（`https://` から）を書くと、サイト名がリンクになります。
- フォント（DotGothic16）とグラフ（Chart.js）は、記入ずみです。

## 見た目

アプリ全体の背景は鉄紺（`#17184b`）です。`css/style.css` の `--bg` で変更できます（枠の中の色は別の変数です）。

## 旧データの整理（任意）

旧バージョンの表は自動では削除しません。不要なら phpMyAdmin で次を実行してください。

```sql
DROP TABLE IF EXISTS buildings, self_study_units, subject_levels;
```
